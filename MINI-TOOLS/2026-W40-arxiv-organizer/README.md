# arXiv 论文快整理(2026-W40)

粘贴任意文本自动抽取 / 去重 arXiv 编号的小工具 —— 单文件纯静态 HTML,零依赖、双击即用、数据不出浏览器。

## 用途

- 把 arXiv 日报 / 周报热词 / 网页复制的一堆论文链接粘进去,自动抠出编号(新旧格式都认)。
- 同一编号不同版本(v1/v2/v3)自动归并去重,保留最新版本标签。
- 一键生成三种格式:Markdown 引用列表 / URL 每行一条 / 纯编号,可复制或导出 .txt。
- 「逐篇打开」点一下开一篇,规避浏览器弹窗拦截;配合 Zotero「文件 → 从剪贴板导入」可批量抓条目入库。

## 用法

1. 双击 `index.html` 在浏览器打开(无需联网,无任何外部资源)。
2. 在上方文本框粘贴素材,输入即自动整理(也可点「填入示例」体验)。
3. 看统计:抽取到编号(含重复)/ 去重后 / 含版本号,以及清单列表(点编号直接打开)。
4. 切换输出格式 →「复制到剪贴板」或「导出 .txt」;或点「逐篇打开」依次开篇。

## 匹配规则

```
新格式  YYMM.NNNNN 或 YYMM.NNNNNvN(年份 07-99、月份 01-12 校验,防误伤)   例:2410.12345v2
旧格式  archive/YYMMNNN 或加 vN                                           例:cs/0101001、hep-th/9901001
前缀    arxiv.org/abs|pdf|html/、arXiv: 均可带可不带
```

形如 `2026.1000`(月份 26 非法)或 `10.1000` 的伪编号会被过滤,不误报。

## 验证说明

- 页面内置自检(`runSelfTest`):加载后自动跑 6 个断言
  (新格式+链接 / 新旧混合 / 版本两处都算原始数 / 版本去重后唯一 / 假编号过滤 / 月份校验),
  全部通过后右上角显示「✓ 自检通过 6/6」且标题前缀变为 `[OK]`。
- 2026-10-08 补跑 W40 时用无头 Edge 实测:`--headless=new --dump-dom` 输出自检徽标为
  `class="ok">✓ 自检通过 6/6`,标题含 `[OK]`,stderr 无页面 JS 报错。
- 端到端注入示例文本后统计:`抽取 6(含重复)→ 去重 5 → 含版本 2`,清单 5 行,
  输出 Markdown 引用列表 5 条,与预期一致。

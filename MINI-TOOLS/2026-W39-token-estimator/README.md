# Token 速算器(2026-W39)

LLM 文本 Token 与调用费用估算器 —— 单文件纯静态 HTML,零依赖、双击即用、数据不出浏览器。

## 用途

- 粘贴提示词 / 文档,实时估算 token 数(中英混排)。
- 按常见模型单价(DeepSeek / GPT / Claude / Qwen)粗算单次输入费用,带可视化对比条。
- 判断一段文本是否超模型上下文窗口、估算 API 成本。

## 用法

1. 双击 `index.html` 在浏览器打开(无需联网,无任何外部资源)。
2. 在文本框中粘贴内容,右侧实时更新统计与 token 估算。
3. 可调"英文系数"(默认 4 字符/token)与"中文系数"(默认 1.2 token/字)。
4. 点"填入示例"可载入一段多模态推荐场景文本体验。
5. 模型单价在页面内 JS 的 `MODELS` 数组中,可自行增删改。

## 估算规则

启发式近似(非官方分词):

```
token ≈ 汉字数 × 中文系数 + 其余字符数 ÷ 英文系数
```

同一文本在不同模型的实际分词结果可能偏差 ±30%,用于粗算额度与成本足够。
